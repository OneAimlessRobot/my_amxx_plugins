Part 3 of extra help file!


(console) sh_print_player_unhealable_hero_skip_flags - Shows a list of damage types a player will heal from even if using unhealable heroes! Requires part of hero name


(console) sh_print_hero_unhealable_hero_skip_flags - Shows a list of heroes that skip unhealable flags!


(console) sh_print_player_projectile_weapons -  A list of projectile weapon flags that a player has due to equipped heroes


(console) sh_print_hero_projectile_weapons - Shows a list of projectile weapons for a hero!
